# 格里菲斯《量子力学概论》（原书第三版）习题参考解析

## 使用说明

- 依据工作区中的英文原书第三版 PDF 编写；正文页码按书页页码标注，而不是 PDF 查看器页码。
- 每章文件分为“节后习题”和“补充习题”（`Further Problems`）两部分。
- 解析默认给出建模思路、关键推导、最终结果和必要检验；涉及数值计算的题目会给出可复现代码或算法。
- 公式中的整体相位若不影响物理结果，通常取最方便的实正归一化常数。
- 这些文件用于做题后的核对。建议先独立完成，再看“思路”，最后核对推导和答案。
